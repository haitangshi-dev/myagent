# AI Agent Onboarding Wizard ⚡

**5 minutes to a productive agent.** Most new users spend a week trying skills that don't work on their system. This wizard scans your environment in ~10 seconds and gives you a focused install list that actually works.

## How to Use

```bash
clawhub install ai-agent-onboarding-wizard
```

Then ask your agent:

> "Run the onboarding wizard"
> "Set me up"
> "What skills should I install?"

## What Happens

1. Wizard scans: your OS, shell, installed tools, system architecture
2. Your agent builds a compatibility matrix of viable skills
3. You get a ranked install list with exact `clawhub install` commands
4. Copy-paste and you're done

**From zero to productive in one session.**

## What You Get

- A working agent setup the first time
- No wasted hours on incompatible skills
- No frustration with broken tools
- A clear path from new user to productive user

## Notes

- Scans in ~10 seconds
- Skips broken, incompatible, or deprecated skills
- Works on all operating systems
